# Local-Note-Encryption-K2D7encrypterMan-
A standalone text editor workspace leveraging authenticated AES-256-GCM encryption engines to lock down local text files containing personal information. Includes automatic inactivity locking timers, dark/light visual modes, and built-in directory sidebar parsing. Has zero bloat-ware and is built for WINDOWS users only. PROTOTYPE.
